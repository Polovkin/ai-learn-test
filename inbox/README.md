# inbox

Temporary drop zone for unsorted files.

Use this folder when you want to save ideas fast without structure.
The agent must later triage and move files into the correct repository areas.

## What can be stored here
- draft markdown notes
- quick code snippets
- scratch assets
- temporary exports

## What should NOT stay here
- stable project code
- final notes
- reusable utilities

## Expected lifecycle
1. Add files here quickly.
2. Ask agent to run inbox triage.
3. Agent classifies each file and moves it.
4. `inbox/` should return to near-empty state.
