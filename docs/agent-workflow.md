# Agent Workflow and Definition of Done

## Workflow
1. Confirm target area (`apps`, `labs`, `packages`, `knowledge-base`, `docs`).
2. Implement minimal, scoped change.
3. Update related documentation (README, map links, notes if needed).
4. Run checks from repo root.
5. Report what changed and why.

## Definition of Done
- Change is placed in the correct top-level area.
- Naming follows repository conventions.
- New lab has a complete README (`goal`, `run`, `result`, `next`).
- New notes/terms are linked from at least one map.
- Workspace checks pass or any failure is clearly explained.
- No unrelated behavior changes were introduced.
