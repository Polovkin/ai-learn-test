# Нотатки

## Поняття

- `Sequential Scan.` - це метод виконання запиту, при якому база даних послідовно переглядає всі рядки таблиці, щоб знайти ті, які відповідають умовам запиту.

## Важливе

SQL - стандарт. Бази данних - це реалізація стандарту. Ананглогія - віджки JS

## Підсумок

Розібрались з індексами, B-tree, композитними індексами. leftmost prefix rule. також.
