# JS code pipeline

- parser (на цьому етапі код розбирається на складові, перевіряється на синтаксичні помилки)
- AST (Abstract Syntax Tree) - дерево, яке описує структуру коду
- bytecode / machine code
- execution (виконання)
- call stack + memory

## Abstract Syntax Tree (AST)

AST - це дерево, яке описує структуру коду. Кожен вузол дерева представляє собою конструкцію мови програмування (наприклад, оператор, функція, змінна тощо). AST використовується для аналізу та оптимізації коду, а також для генерації машинного коду.
