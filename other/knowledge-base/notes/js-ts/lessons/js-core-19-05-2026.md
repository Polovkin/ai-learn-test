# Terms

- Execution context - оточення в якому запускається js
- Just-In-Time compilation - компіляція коду(текстового) в процесі виконання

# Основні JS-engines

- SpiderMonkey - Firefox
- V8 - Chrome, Edge, Opera, Node.js
- JavaScriptCore - Safari

Вони реалізують ОДНУ spec (ECMAScript), але різними внутрішніми механізмами

Browser складається приблизно з:

1. JS engine
   Виконує JS.
2. Rendering engine
   Малює сторінку.
3. Browser APIs
   DOM, fetch, timers, storage.
4. Networking layer
   HTTP/TLS/cache/cookies.
5. UI/browser shell
   Tabs, address bar, history.
