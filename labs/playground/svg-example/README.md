# SVG Line Chart

## Goal

Create a minimal line chart from a plain TypeScript array and SVG.

## Run

From `labs/playground`:

```bash
npm run svg:dev
```

## Result

TypeScript converts array values into SVG coordinates. SVG displays axes,
grid lines, a polyline, data points, and labels.

## What I Learned

- How to convert data values into X and Y coordinates.
- How to draw a line with SVG `<polyline>`.
- How to create SVG elements from TypeScript.
