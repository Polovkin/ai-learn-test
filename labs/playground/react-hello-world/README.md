# React Hello World

## Goal

Створити мінімальний застосунок на React і TypeScript без метафреймворків.

## Run

З папки `labs/playground`:

```bash
npm run react:dev
```

## Result

Vite запускає локальну сторінку з React-компонентом `App`, який показує
привітання.

## What I Learned

- Як змонтувати React-застосунок через `createRoot`.
- Як створити й підключити простий React-компонент.
- Як типізувати props React-компонента.
- Як запускати React через Vite.
